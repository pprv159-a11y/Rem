# Remotion Studio — Единственный правитель мира

Vertical 9:16 cinematic explainer video with Russian narration and an original ambient soundtrack.

## Render MP4 in GitHub Actions

1. Open the Actions tab.
2. Select Render Remotion video.
3. Click Run workflow (or open a pull-request run).
4. Wait for all validation and rendering steps to finish.
5. Download the remotion-video-9x16 artifact from the completed run.

The workflow checks TypeScript, validates Remotion package versions and the composition list, ensures the Remotion-managed Chrome Headless Shell is installed, generates narration and music, renders the MP4, verifies its media metadata, and uploads the artifact.

## Narration

The workflow first attempts Microsoft Edge TTS using the Russian voice ru-RU-DmitryNeural, splitting the narration into paragraphs and retrying failed requests. If the online TTS service does not return audio, it uses the free offline eSpeak NG Russian voice. The offline voice is less natural but avoids making the entire render depend on the external Edge TTS service.

Edit public/narration.txt to change the spoken text. The generated public/narration.mp3 is created during the workflow and is not committed to the repository.

## Audio and video settings

- Resolution: 1080 x 1920 (9:16)
- Frame rate: 30 FPS
- Duration: 300 seconds
- Video codec: H.264
- Music: original 16-bit stereo WAV generated by scripts/create_soundtrack.py

The workflow validates that narration and soundtrack exist, checks the soundtrack duration, and verifies the final MP4 dimensions, frame rate, duration, codec, and audio stream before uploading the artifact.

## Local development

Use Node.js 20 and Python 3.11. Install the system packages FFmpeg and eSpeak NG, then install project packages with npm ci after a lockfile exists, or npm install for initial setup.

Run npm run check, then python scripts/generate_narration.py, python scripts/create_soundtrack.py, python scripts/validate_media.py --assets-only, npx remotion browser ensure, npm run render, and python scripts/validate_media.py --video out/video.mp4.

The CI workflow bootstraps package-lock.json on its first run and commits it to the same-repository branch. Subsequent runs use npm ci for reproducible dependency installation.
